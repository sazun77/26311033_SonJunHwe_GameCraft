## 플레이 방식
- 메인 메뉴(구현 예정)에서 시작과 종료 중 하나 선택.
- 어드벤쳐 파트에서 선택지 마우스로 선택.
    - 키보드 보다는 마우스로 조작하는 것이 더 몰입된다 생각하는 편이라서.
- 전투는 손놓고 구경하도록 만들 것.
    - 일일히 입력 가능하게 설계하는 것도 복잡하고(사실 input = NULL이면 진행도 올리지 않고 return 시키는 느김으로 구현하면 될 것 같긴 한데...) 흐름 끊길 것 같으니 자동 전투.
- 전투 종료 시 보상 선택 때 입력이 필요함.

- 어드벤처 파트와 보상 선택에서 선택과 집중 == 덱 빌딩과 탐험의 재미 같은 것이 주요 재미 포인트.
- 전투 감상하며 "캬 역시 잘 컸다."하면서 성장의 재미 느끼는 것이 메인.
